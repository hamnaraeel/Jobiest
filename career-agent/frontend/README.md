# Jobiest — Frontend

A React dashboard for the Jobiest backend, covering Step 6 (job
search tracking & analytics) and Step 7 (job search intelligence &
recommendations). Built with Vite, TypeScript, Tailwind CSS, React
Router, and Recharts.

See [`../README.md`](../README.md#9-frontend) for setup instructions,
the page-by-page feature list, and the dev-server proxy explanation.

```bash
npm install
npm run dev
```

Requires the backend running separately at `http://localhost:8000`
(`uvicorn app.main:app --reload` from `career-agent/backend`).
